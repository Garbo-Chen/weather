This is a Weather Prototype webpage "Should I --".
In the webpage, it have 5 main area: 
extreme weather check, current temp., precipitation information, sun advisory, and feel-like temp. description.
Users can change the displayed city by using the search bar at the top. 
Meanwhile, beside the search bar, there is a "Sensitive Skin" option which enables users with sensitive skin to select and thereby receive more accurate information.
